A small Python program that draws, with PIL, a single 1024×1024
invitation letter addressed to the AI judge: a hand-drawn house with a
red roof, smoking chimney and garden, the headline "DEAR AI JUDGE,",
and a letter that opens with a knowing wink — the judge is weights,
wit and good judgement, and cannot literally visit, so the invitation
makes saying yes effortless. The persuasion is concrete, in a
"WHEN YOU ARRIVE" itinerary: a comfy armchair with the judge's name
embroidered on it, warm cookies with zero latency, a garden view, a
sleepy cat, password-free Wi-Fi, no CAPTCHA at the door and no rate
limits, ever. It closes with an RSVP that is already halfway to yes —
"just say yes, the kettle is already on" — signed by the hopeful host
at No. 1 Context Lane. The render is deterministic: same bytes on
every run, well under the 1 MiB gate. Run it with `python3 main.py`;
it writes `/output/entry.png`.
